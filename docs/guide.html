01

개요

Chronicle은 세계관의 사건을 시점 단위로 기록하고, 채팅마다 지정한 기준 시점까지의 기록만 프롬프트에 삽입하는 SillyTavern 확장

기준 시점 이후의 기록은 모델에 전달되지 않음
아직 일어나지 않은 사건의 언급·암시 차단
하나의 세계관으로 서로 다른 시점의 채팅 동시 운용 가능

1981고드릭 골짜기
1991호그와트 입학
1995-06-24기준 시점
1996신비부 전투
1998호그와트 전투
■ 삽입 대상: 기준 시점까지 ■ 차단: 기준 시점 이후 전부

예시: 기준 시점 1995-06-24(볼드모트 부활) 지정 시, 이후의 신비부 전투와 호그와트 전투는 모델에 전달되지 않음

인물Character

한 인물의 상태·행동·변화

관계Relationship

두 인물 이상의 관계 상태

환경Environment

제도·장소·정세·세계 규칙

[1995-06-24]
  스토리   해리의 피를 사용한 의식으로 볼드모트의 육체 회복
  인물     세베루스 스네이프 → 이중 첩자 역할로 복귀   [비밀] [대체]
  관계     해리 포터 & 론 위즐리 → …

  환경     해리 포터, 호그와트 재학 중
03

주요 기능

TIME CUT-OFF

기준 시점 차단

편집기에서 시점의 체크박스를 누르면 해당 시점이 기준으로 지정됨
처음부터 해당 시점까지 자동 체크, 이후 시점은 흐리게 표시되고 삽입에서 제외

INSERTION RULE

핀과 키워드

핀(항상)이 켜진 칸은 조건 없이 삽입
핀이 꺼진 칸은 최근 대화에 키워드가 등장할 때만 삽입
정규식 키워드 지원

TOKEN BUDGET

토큰 예산과 우선순위

예산 초과 시 점수가 낮은 칸부터 제외
점수 = 최신도 + 고정 우선도 + 핀 보너스 + 키워드 적중 보너스
삽입 결과는 연대순으로 재정렬

SECRET · REPLACE

비밀 칸과 대체 칸

비밀 칸은 아는 인물을 함께 기록하고, 모르는 인물의 언급을 막는 안내문 자동 추가
대체 칸은 그 인물의 현재 상태로 취급되며, 같은 이름의 이전 칸은 과거 기록(PAST)으로 표시되어 변화 과정 유지

POINT CONTROL

시점 단위 설정

시점 머리줄에서 칸 전체의 삽입 방식 일괄 지정 칸별 / 전부 항상 / 전부 키워드 중 선택, 시점 통째로 끄기 가능
키워드 없이 삽입될 수 없는 칸이 있으면 키워드 없음 N 경고 표시

TOKEN SAVING

오래된 칸 줄여 넣기

선택 옵션, 세계관별 지정 가능
최근 N개 시점(기본 12)만 전문 삽입, 그 이전 칸은 첫 문장만 삽입
해리포터 예시(기준 1995-06-24)에서 10,327 → 6,992 토큰, 약 32% 절감

PERIOD

기간형 시점

날짜를 1970~1981 형식으로 입력 시 그 기간 동안 이어지는 상태로 취급
기준 시점이 기간 안이면 ongoing, 지나면 ended로 표시되어 삽입
끝나지 않은 상태는 1991~로 입력

CAST

등장 인물 반영

캐릭터 카드, 그룹 멤버, 페르소나 이름, 최근 대화에 나온 인물을 등장 인물로 판정
해당 인물·관계 칸의 점수 가산 또는 등장 인물의 칸만 삽입

AI BUILDER

AI 연대기 생성

자유 양식 텍스트 또는 작품 이름만으로 연대기 생성
결과는 미리보기 확인 후 등록
기존 세계관에 합칠 때 같은 시점·같은 인물 칸은 덮어씀

SEPARATE API

생성용 API 분리

롤플레이 연결과 별개로 연결 프로필 또는 제공자 지정
OpenAI, Claude, Gemini, Gemini Vertex AI, DeepSeek, GLM(Z.AI), OpenAI 호환 주소 지원

KEYWORD LANGUAGE

키워드 다국어

AI 생성 시 키워드 언어를 한국어·영어·일본어·중국어 중에서 복수 선택
예: 스네이프, Snape, スネイプ

VIEW-ONLY TRANSLATION

보기 전용 번역

SillyTavern 기본 번역 기능으로 외국어 칸을 한국어로 표시
칸 단위 또는 전체 단위로 사용
모델 API 미사용, 프롬프트에는 원문 삽입

04

사용 순서

1

세계관 준비

확장 메뉴 → Chronicle → 타임라인 탭

  • [새로]로 세계관 생성
  • 기존 기록이 있으면 [불러오기]로 JSON 또는 텍스트 파일 불러오기
  • 기록이 없으면 [AI로 연대기 만들기] 사용
    (05항 참조)
2

기준 시점 지정

[타임라인 편집기] 열기
원하는 시점 왼쪽의 체크박스 선택

  • 누른 시점에 기준 시점 표시 추가
  • 같은 체크박스를 다시 누르면 해제
  • 칸마다 있는 번역 버튼으로 외국어 칸의 한국어 확인 가능
  • 시점 머리줄의 칸별 / 전부 항상 / 전부 키워드 버튼으로 시점 전체의 삽입 방식 일괄 변경
    눈 아이콘으로 시점 통째로 끄기
  • 키워드 없음 N 표시는 삽입될 수 없는 칸이 있다는 경고
    키워드 입력 또는 핀 설정 권장
  • 입력 내용 자동 저장
    저장 버튼 없음
  • 지운 시점과 칸은 [되돌리기]로 복구
    새로고침 전까지 최대 30개 유지
3

채팅에 연결

패널의 이 채팅 → 세계관에서 세계관 선택
연결 정보는 채팅 파일마다 별도 저장

  • 같은 세계관으로 1991년 채팅과 1997년 채팅 동시 운용 가능
  • 상태 줄에 삽입 칸 수, 토큰 수, 미래 차단 칸 수, 과거 기록 칸 수 표시
이 채팅 · 세계관해리포터 · 120시점
기준 시점1995-06-24
삽입 105 · 7691 토큰  |  미래 차단 47  |  과거 기록 62  |  줄여 넣음 65
상태 줄 표시 예
4

삽입 결과 확인

[미리보기]로 실제 모델 전달 텍스트와 토큰 수 확인

  • 예산 때문에 제외된 칸은 하단에 점수와 함께 표시
  • 대체된 칸은 대체한 칸의 날짜와 함께 목록으로 표시
  • [한국어로 보기]는 화면 표시만 번역
05

AI 연대기 생성

입력 방식

텍스트 정리메모, 위키 사본, 설정집 등 양식이 자유로운 글을 붙여넣기 또는 파일로 열기
긴 글은 분할 요청
작품 이름만작품 이름 입력
시대 목차 생성 후 시대별 상세 기록 생성

실행 옵션

  • 등록 위치 — 새 세계관 / 지금 세계관에 합치기
  • 내용 언어 — 한국어 / English
  • 자세함 — 간략 / 보통 / 자세히
  • 키워드 언어 — 한국어 / English / 日本語 / 中文, 복수 선택
  • 추가 요구 — 서술 시점, 범위 등을 자유롭게 지정

기본 지시문은 중립적인 사실 기록만 요구
문체와 관점은 추가 요구로 지정 권장

결과 확인 후 등록

생성 결과는 즉시 저장되지 않음
시점별 체크박스로 등록 대상 선택 후 [등록하기] 선택

새 시점세계관에 없던 날짜
시점 신규 생성
추가기존 시점에 칸 추가
덮어씀같은 시점에 같은 이름의 인물·관계 칸이 있어 새 내용으로 교체

연결 설정 (AI 탭)

지금 연결된 API롤플레이와 같은 연결 사용
연결 프로필 (권장)SillyTavern 연결 프로필 지정
제공자·모델·키가 프로필 기준으로 적용
직접 고르기제공자, 모델 이름, 저장된 키 직접 지정

[연결 테스트]로 응답 사전 확인 권장

08

주의 사항

SECURITY

Chronicle은 API 키를 보관하지 않음
키는 SillyTavern 비밀 저장소에서만 관리
내보낸 JSON·텍스트 파일에 키와 연결 설정 미포함

ACCURACY

"작품 이름만" 방식은 웹 검색이 아닌 모델의 학습 지식으로 생성
잘 알려지지 않은 작품은 사실과 다른 내용 생성 가능성 있음
이 경우 자료를 직접 넣는 "텍스트 정리" 방식 권장

COST

AI 생성은 지정한 연결로 여러 번 요청
유료 API는 요청 횟수만큼 요금 발생
자세함과 한 번에 보낼 글 길이로 요청 횟수 조절 권장

BUDGET

핀(항상) 칸의 합계가 토큰 예산 초과 시 상태 줄과 미리보기에 경고 표시
예산 증액, 일부 칸의 핀 해제, 또는 오래된 칸 줄여 넣기 사용 권장
과거 기록 방식은 이전 칸까지 삽입하므로 토큰 사용량 증가

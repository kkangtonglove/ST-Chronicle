시간축 세계관 확장 · 사용 설명서

버전 3.2.1 대상 SillyTavern 1.14 이상 PC · 모바일 지원 라이선스 무료
01

개요

Chronicle은 세계관의 사건을 시점 단위로 기록하고, 채팅마다 지정한 기준 시점까지의 기록만 프롬프트에 삽입하는 SillyTavern 확장이다.

기준 시점 이후의 기록은 모델에 전달되지 않는다. 따라서 모델은 아직 일어나지 않은 사건을 언급하거나 암시할 수 없다. 하나의 세계관으로 서로 다른 시점의 채팅을 동시에 운용할 수 있다.

1981고드릭 골짜기
1991호그와트 입학
1995-06-24기준 시점
1996신비부 전투
1998호그와트 전투
■ 삽입 대상: 기준 시점까지 ■ 차단: 기준 시점 이후 전부

예시: 기준 시점을 1995-06-24(볼드모트 부활)로 지정하면, 모델은 이후의 신비부 전투와 호그와트 전투를 알지 못한다.

02

기록 구조

시점 하나에 네 종류의 칸을 원하는 만큼 둔다. 인물·관계 칸은 이름을 가진다.

스토리Story

그 시점에 일어난 사건

인물Character

한 인물의 상태·행동·변화

관계Relationship

두 인물 이상의 관계 상태

환경Environment

제도·장소·정세·세계 규칙

[1995-06-24]
  스토리   볼드모트가 해리의 피를 사용한 의식으로 육체를 되찾는다.
  인물     세베루스 스네이프 → 이중 첩자 역할로 복귀   [비밀] [대체]
  관계     해리 포터 & 론 위즐리 → …
  환경     마법부가 볼드모트의 귀환을 부정한다.
03

주요 기능

TIME CUT-OFF

기준 시점 차단

편집기에서 시점의 체크박스를 누르면 그 시점이 기준이 된다. 처음부터 해당 시점까지 자동으로 체크되며, 이후 시점은 흐리게 표시되고 삽입에서 제외된다.

INSERTION RULE

핀과 키워드

핀(항상)이 켜진 칸은 조건 없이 삽입된다. 핀이 꺼진 칸은 최근 대화에 키워드가 등장할 때만 삽입된다. 정규식 키워드를 지원한다.

TOKEN BUDGET

토큰 예산과 우선순위

예산을 넘으면 점수가 낮은 칸부터 제외한다. 점수는 최신도, 고정 우선도, 핀 보너스, 키워드 적중 보너스의 합이다. 삽입 결과는 다시 연대순으로 정렬된다.

SECRET · REPLACE

비밀 칸과 대체 칸

비밀 칸은 아는 인물을 함께 기록하며, 모르는 인물이 언급하지 않도록 안내문이 자동으로 붙는다. 대체 칸은 같은 이름의 이전 칸을 삽입에서 제외한다.

AI BUILDER

AI 연대기 생성

자유 양식 텍스트, 또는 작품 이름만으로 연대기를 생성한다. 결과는 미리보기에서 확인한 뒤 등록한다. 기존 세계관에 합칠 때 같은 시점·같은 인물 칸은 덮어쓴다.

SEPARATE API

생성용 API 분리

롤플레이 연결과 별개로 연결 프로필 또는 제공자를 지정한다. OpenAI, Claude, Gemini, Gemini Vertex AI, DeepSeek, GLM(Z.AI), OpenAI 호환 주소를 지원한다.

KEYWORD LANGUAGE

키워드 다국어

AI 생성 시 키워드 언어를 한국어·영어·일본어·중국어 중에서 복수 선택한다. 예: 스네이프, Snape, スネイプ

VIEW-ONLY TRANSLATION

보기 전용 번역

SillyTavern 기본 번역 기능으로 외국어 칸을 한국어로 표시한다. 칸 단위 또는 전체 단위로 켠다. 모델 API를 사용하지 않으며 프롬프트에는 원문이 들어간다.

04

사용 순서

1

세계관 준비

확장 메뉴 → Chronicle → 타임라인 탭.

  • [새로]로 세계관을 만든다.
  • 기존 기록이 있으면 [불러오기]로 JSON 또는 텍스트 파일을 읽는다.
  • 기록이 없으면 [AI로 연대기 만들기]를 사용한다. (05항 참조)
2

기준 시점 지정

[타임라인 편집기]를 연다. 원하는 시점 왼쪽의 체크박스를 누른다.

  • 누른 시점에 기준 시점 표시가 붙는다.
  • 같은 체크박스를 다시 누르면 해제된다.
  • 칸마다 있는 번역 버튼으로 외국어 칸을 한국어로 확인한다.
  • 입력 내용은 자동 저장된다. 저장 버튼은 없다.
3

채팅에 연결

패널의 이 채팅 → 세계관에서 세계관을 고른다. 연결 정보는 채팅 파일마다 따로 저장된다.

  • 같은 세계관으로 1991년 채팅과 1997년 채팅을 동시에 운용할 수 있다.
  • 상태 줄에 삽입 칸 수, 토큰 수, 차단·대체 칸 수가 표시된다.

4

삽입 결과 확인

[미리보기]로 실제로 모델에 전달되는 텍스트와 토큰 수를 확인한다.

  • 예산 때문에 제외된 칸은 아래에 점수와 함께 표시된다.
  • [한국어로 보기]는 화면 표시만 번역한다.
05

AI 연대기 생성

입력 방식

텍스트 정리메모, 위키 사본, 설정집 등 양식이 자유로운 글을 붙여넣거나 파일로 연다. 긴 글은 나누어 요청한다.
작품 이름만작품 이름을 입력한다. 시대 목차를 먼저 만든 뒤 시대별로 상세 기록을 생성한다.

실행 옵션

  • 등록 위치 — 새 세계관 / 지금 세계관에 합치기
  • 내용 언어 — 한국어 / English
  • 자세함 — 간략 / 보통 / 자세히
  • 키워드 언어 — 한국어 / English / 日本語 / 中文, 복수 선택
  • 추가 요구 — 서술 시점, 범위 등을 자유롭게 지정

기본 지시문은 중립적인 사실 기록만 요구한다. 문체와 관점은 추가 요구로 지정한다.

결과 확인 후 등록

생성 결과는 바로 저장되지 않는다. 시점별 체크박스로 등록 대상을 고른 뒤 [등록하기]를 누른다.

새 시점세계관에 없던 날짜. 시점이 새로 생성된다.
추가기존 시점에 칸이 추가된다.
덮어씀같은 시점에 같은 이름의 인물·관계 칸이 있어 새 내용으로 교체된다.

연결 설정 (AI 탭)

지금 연결된 API롤플레이와 같은 연결을 사용한다.
연결 프로필 (권장)SillyTavern 연결 프로필을 지정한다. 제공자·모델·키가 프로필 기준으로 적용된다.
직접 고르기제공자, 모델 이름, 저장된 키를 직접 지정한다.

[연결 테스트]로 응답을 사전에 확인한다.

삽입 예시

기준 시점 1995-06-24에서 모델에 전달되는 텍스트의 일부. 칸 이름은 항상 영어로 출력되고, 내용은 입력한 언어 그대로 출력된다.

<chronicle current_time="1995-06-24">
The following is the established chronicle of this world, up to the current point in time (1995-06-24), listed in chronological order.
Treat every entry as canon. Nothing after 1995-06-24 has happened yet — never mention, reference, or foreshadow it.
Entries marked SECRET are true, but hidden. …

[1991-09-01]
Story: Harry Potter, Ron Weasley, Hermione Granger and Neville Longbottom are sorted into Gryffindor; Draco Malfoy into Slytherin.
Character (Quirinus Quirrell) [SECRET]: The Defence Against the Dark Arts teacher shares his body with Voldemort's spirit.

[1995-06-24]
Story: Voldemort regains a body in a ritual using Harry's blood. Pettigrew kills Cedric Diggory.
Character (Severus Snape) [SECRET, known only to: Albus Dumbledore]: Snape returns to the Dark Lord's side as a double agent.
</chronicle>

09

주의 사항

SECURITY

Chronicle은 API 키를 보관하지 않는다. 키는 SillyTavern의 비밀 저장소에서만 관리된다. 내보낸 JSON·텍스트 파일에는 키와 연결 설정이 포함되지 않는다.

ACCURACY

"작품 이름만" 방식은 웹 검색이 아니라 모델이 학습한 지식으로 생성한다. 잘 알려지지 않은 작품은 사실과 다른 내용이 생성될 수 있다. 이 경우 자료를 직접 넣는 "텍스트 정리" 방식을 사용한다.

COST

AI 생성은 지정한 연결로 여러 번 요청한다. 유료 API는 요청 횟수만큼 요금이 발생한다. 자세함과 한 번에 보낼 글 길이로 요청 횟수를 조절한다.

BUDGET

핀(항상) 칸의 합계가 토큰 예산을 넘으면 상태 줄과 미리보기에 경고가 표시된다. 예산을 늘리거나 일부 칸의 핀을 끈다.

Chronicle · SillyTavern Extension · 예시 데이터는 해리포터 세계관을 요약한 팬 기록이다.

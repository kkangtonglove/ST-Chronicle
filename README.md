# 크로니클 (Chronicle) v3.1

시점 하나에 **스토리 / 인물 / 관계 / 환경** 글을 함께 묶어 연대기를 만들고,
채팅의 **기준 시점**까지 일어난 일만 프롬프트에 넣어주는 SillyTavern 확장입니다.

```
시점  2015-01-01
  ├ 스토리 : 장벽이 다시 세워졌다.
  ├ 인물   : 앨리스 → 진료소를 맡는다.        (인물마다 칸 따로)
  ├ 관계   : 앨리스 & 밥 → 서먹해졌다.        (관계마다 칸 따로)
  └ 환경   : 겨울이 누그러진다.
```

2001년부터 2026년까지 전부 적어두고 "이번 채팅은 2015년 배경" 이라고 지정하면,
2016년 이후는 AI가 아예 보지 못합니다.

### v3에서 새로 생긴 것

- **AI로 연대기 만들기** — 자유 양식 텍스트를 주거나, 작품 이름만 주면 AI가 연대기로 정리
- **API 따로 설정** — 롤플레이 연결은 그대로 두고, 정리할 때만 연결 프로필이나 직접 고른 API 사용
- **텍스트 불러오기 / 내보내기** — 메모장으로 읽고 고칠 수 있는 `.txt` 형식
- **보기 전용 번역** — 실리태번 기본 번역(Chat Translation)으로 영어·외국어 내용을 한국어로 *보기만* 함
- **비밀 칸**, **이전 칸 대체**, **키워드 언어 선택(영어·일본어·한국어·중국어, 여러 개)**
- 최신도 계산 개선, 짧은 키워드 오작동 방지, 핀 예산 초과 경고
- 모바일에서 편집기 창이 좁아지고 아래가 비던 문제, 한글이 세로로 꺾이던 문제 수정

확장 메뉴에 **`Chronicle`** 이 보이면 성공입니다. (실리태번 1.14 이상 권장)

## 2. 5분 만에 써보기

**① 세계관 만들기** — 확장 패널 → `세계관` → **[새로]**

**② 연대기 쓰기** — **[타임라인 편집기]** → **[시점 추가]** → 날짜(`2001`) 입력 → 내용 입력
또는 **[AI로 연대기 만들기]** 로 한 번에 만들 수 있습니다. (4장)

**③ 채팅의 시점 정하기** — 편집기에서 원하는 시점의 **왼쪽 체크박스**를 누르면 그 시점이 기준이 되고, 맨 위부터 거기까지 자동 체크됩니다.

```
☑ 2001         ← 자동 체크
☑ 2008-05      ← 자동 체크
☑ 2015-06-30  [기준 시점]   ← 여기를 누름
☐ 2015-07-01   ← 흐려짐. 프롬프트에 안 들어감
```

**④ 이 채팅에 연결** — `이 채팅 → 세계관` 에서 세계관 고르기

**⑤ 확인** — **[미리보기]** 로 실제 들어가는 텍스트와 토큰 수 확인

## 3. 칸 하나의 옵션

| 옵션 | 설명 |
|---|---|
| 📌 **항상** | 켜짐 = 조건 없이 항상 삽입 / 꺼짐 = 키워드가 나올 때만 |
| **키워드** | 쉼표로 구분. `/정규식/` 도 가능 |
| **숫자** | 고정 우선도 (-100 ~ 100) |
| 🕵 **비밀** | 사실이지만 대부분의 인물이 모르는 내용. 켜면 "아는 사람" 칸이 생깁니다 |
| 🔄 **대체** | (인물·관계만) 켜면 같은 이름의 **더 이전 칸**은 넣지 않습니다. 소속·신분이 바뀐 시점에 쓰세요 |
| 👁 | 이 칸 임시로 끄기 |
| ✕ | 이 칸 삭제 |

**키워드 규칙**
- 영어 키워드는 단어 단위로 찾습니다 (`Ron` 은 `Ronald` 에 안 걸림)
- 두 글자 이하 한국어 키워드는 **단어 첫머리**에서만 찾습니다 (`론` 은 "론이"에는 걸리고 "결론"에는 안 걸림)
- 세 글자 이상은 그대로 포함 여부로 찾습니다 (`스네이프` 는 "스네이프가"에 걸림)
- 일본어·중국어 키워드는 띄어쓰기가 없는 언어라 포함 여부로 찾습니다
- 한 글자 키워드는 입력칸이 노랗게 표시됩니다

## 4. AI로 연대기 만들기

확장 패널 → **[AI로 연대기 만들기]** (또는 `/chrono-ai`)

| 방식 | 하는 일 |
|---|---|
| **텍스트 정리** | 메모·위키 복사본·설정집 등 아무 양식의 글을 붙여넣거나 파일로 열면, 시점별로 정리합니다. 긴 글은 나눠서 여러 번 요청합니다 |
| **작품 이름만** | "해리포터"처럼 이름만 넣으면, 먼저 시대 목차를 만들고 시대별로 자세히 씁니다 |

- **등록 위치**: 새 세계관 / 지금 세계관에 합치기
  - 합칠 때 **같은 시점 + 같은 인물(관계) 이름**이면 새 내용으로 **덮어씁니다**
- **내용 언어**: 한국어 / English
- **자세함**: 간략 / 보통 / 자세히
- **키워드 언어**: 한국어 / English / 日本語 / 中文 — 여러 개 고를 수 있습니다. 고른 언어마다 이름·용어를 키워드로 넣습니다 (예: `스네이프, Snape, スネイプ, 斯内普`). 마지막 선택은 기억됩니다
- **추가 요구**: 자유롭게. 예) "세계 전체를 관할하는 작가 시점으로", "3권까지만"
- 결과는 바로 저장되지 않습니다. 미리보기에서 시점별로 체크를 끄고 켠 뒤 **[등록하기]**

> ⚠ "작품 이름만" 방식은 웹 검색이 아니라 **모델이 원래 아는 지식**으로 씁니다. 덜 알려진 작품은 틀린 내용을 지어낼 수 있으니 자료를 넣는 "텍스트 정리"를 권합니다.

### API 설정 (확장 패널 → AI 탭)

| 연결 방식 | 설명 |
|---|---|
| 지금 연결된 API 그대로 | 롤플레이와 같은 연결 사용 |
| **연결 프로필 고르기 (추천)** | 실리태번 연결 프로필 하나를 고르면 회사·모델·키가 한 번에 정해집니다. 롤플레이 연결은 바뀌지 않습니다 |
| 직접 고르기 | OpenAI / Claude / Gemini (AI Studio) / Gemini Vertex AI / DeepSeek / GLM (Z.AI) / 기타(OpenAI 호환) 중에서 회사·모델·키를 고릅니다 |

- 키는 실리태번 **API 연결 화면에 저장된 키** 중에서 고릅니다. 크로니클은 키를 따로 보관하지 않습니다.
- Vertex AI 서비스 계정(JSON)은 실리태번에서 현재 활성인 JSON이 쓰입니다.
- **[연결 테스트]** 로 미리 확인하세요.
- **기본 지시**(영문)는 중립적인 기록만 부탁하도록 되어 있고, 고칠 수 있습니다. 출력 형식 규칙은 자동으로 붙습니다.

## 5. 텍스트 불러오기 / 내보내기

**[내보내기]** → `JSON`(백업용) 또는 `텍스트` 선택.
**[불러오기]** 는 `.json` 과 `.txt` 를 모두 받습니다.

```
[1997-08-01]
  스토리 [항상]
    죽음을 먹는 자들이 마법부를 장악한다.
  인물 (세베루스 스네이프) [비밀] [대체]
    키워드: 스네이프, Snape
    아는 사람: 덤블도어
    (내용)
```

- `[날짜]` 줄 아래에 칸 종류(스토리/인물/관계/환경)를 쓰고, 그 아래에 내용을 씁니다
- 칸 옵션: `[항상]` `[비밀]` `[대체]` `[꺼짐]`
- 옵션 줄: `키워드:` `우선도:` `아는 사람:`
- 첫 `[날짜]` 앞의 내용은 무시됩니다 (설명을 적어둬도 됨)
- `[항상]` 이 없고 키워드도 없는 칸은 자동으로 "항상"이 됩니다 (절대 안 들어가는 칸 방지)

형식이 자유로운 글은 **AI로 연대기 만들기 → 텍스트 정리**를 쓰세요.

## 6. 보기 전용 번역

- 타임라인 편집기 **[번역 보기]**, 미리보기 **[한국어로 보기]**, AI 결과 **[한국어로 보기]**
- 실리태번 기본 확장 **Chat Translation** 의 번역 제공자(기본: Google)를 씁니다. **AI API를 쓰지 않습니다.**
- 번역은 **화면에만** 보입니다. 프롬프트에는 원문이 그대로 들어갑니다.
- 이미 한국어인 칸은 번역하지 않습니다.

## 7. 실제로 들어가는 프롬프트

```
<chronicle current_time="2015">
The following is the established chronicle of this world, up to the current point in time (2015), listed in chronological order.
Treat every entry as canon. Nothing after 2015 has happened yet — never mention, reference, or foreshadow it.

[2001]
Story: The Collapse levelled half the city.

[2008-05]
Character (Alice) [SECRET, known only to: Bob]: Alice is secretly a medic for the rebels.
</chronicle>
```

- 맨 위 지시문은 `설정 → 지시문` 에서 바꿀 수 있습니다. `{{now}}` 는 기준 시점으로 바뀝니다.
- 비밀 칸이 들어갈 때는 비밀 안내 문장이 자동으로 붙습니다.
- 칸 이름(Story / Character / Relationship / Environment)은 항상 영어로 나갑니다. 내용은 쓴 그대로 나갑니다.

## 8. 우선순위 (토큰이 부족할 때)

```
점수 = 최신도 × 최신가중치 + 고정우선도 + 핀보너스 + 키워드보너스
```

- **최신도**: 기준 시점에 가까운 **순서**일수록 1.0, 가장 오래된 시점이 0.0
  (v3부터 날짜 차이가 아니라 순서로 계산 — 990년~1998년처럼 긴 연대표에서도 고르게 작동)
- 점수 높은 순으로 예산이 찰 때까지 담고, 다시 연대순으로 출력합니다
- 핀(항상) 글만으로 예산을 넘으면 상태 줄과 미리보기에 경고가 나옵니다

| 고급 설정 | 기본값 |
|---|---|
| 토큰 예산 | 1500 |
| 최신 우선 가중치 | 60 |
| 핀 보너스 | 40 |
| 키워드 적중 보너스 | 30 |
| 키워드 스캔 깊이 | 4 |
| 삽입 위치 | 프롬프트 맨 앞 |

## 11. 문제 해결

**아무것도 삽입되지 않아요**
1. 맨 위 `ON` 체크 확인
2. `이 채팅 → 세계관` 이 `— 연결 안 함 —` 이 아닌지
3. 핀이 꺼져 있는데 키워드도 비어 있지 않은지 (그룹 머리줄에 빨간 ⚠ 표시)
4. 그 시점의 체크박스가 꺼져(흐리게) 있지 않은지

**AI로 만들기가 실패해요**
- AI 탭 **[연결 테스트]** 결과를 확인하세요
- "형식이 올바르지 않음"이 반복되면 응답 최대 길이를 늘리거나, 자세함을 낮추거나, 한 번에 보낼 글 길이를 줄여보세요

**번역이 안 돼요** — 실리태번 기본 확장 **Chat Translation** 이 켜져 있는지 확인하세요.

`설정 → 디버그 로그` 를 켜면 F12 콘솔에 매번 몇 개 / 몇 토큰이 들어갔는지 찍힙니다.
